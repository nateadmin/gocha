# App Store privacy details (Gocha 1.0)

Draft answers for App Store Connect → App Privacy. Verify against production before submission.

## Data linked to you

- Contact info: email, phone number
- Identifiers: user ID
- User content: messages, photos, videos, profile information
- Usage data: product interaction (if analytics enabled)

## Data used to track you

None declared for v1.0 unless advertising SDKs are added later.

## Purposes

- App functionality (messaging, auth, profiles)
- Product personalization (language, Catch Up briefings)
- Analytics (crash and performance, if enabled)

## Third-party partners

- Firebase Authentication
- OpenAI API (Catch Up and Gocha AI)
- Google Places API (business address autocomplete)
