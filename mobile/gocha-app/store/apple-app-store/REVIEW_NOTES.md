# App Review Information (paste into App Store Connect)

**Sign-in required:** Yes

**User name:** `google-review@gocha.ai`
**Password:** _the value of `GOCHA_REVIEW_LOGIN_PASSWORD` in Infisical (project `gocha`). Do not commit it._

## Notes for the reviewer

1. On the first screen tap **Sign in**, type `google-review@gocha.ai` and a
   **Password** field appears. Enter the password and tap Continue. No code is needed.
2. A one-time "Before you continue" screen asks you to agree to the community
   rules and to choose whether to allow AI features. Agree and tap Continue.
3. Sign-in on iPhone uses email. Phone sign-in is only available on the web
   version (https://app.gocha.ai).

**User-generated content safety (Guideline 1.2):**
- Report a chat: open a chat, menu (top right) → Report. Report one message:
  long-press a message → Report message. Report a status: open it → flag icon.
- Block: open a chat → menu → Block (in a group, long-press a member's message →
  Block). Blocked people cannot message you and are hidden from search and statuses.
- Terms: agreed on the "Before you continue" screen; the Terms of Use and Privacy
  Policy open from Settings.
- Reports are reviewed within 24 hours (support@gocha.ai).

**Account deletion (Guideline 5.1.1(v)):** Settings → scroll to the bottom →
**Delete account**.

**AI (Guideline 5.1.2):** AI features are off until the user turns them on.
Message text is sent to OpenAI only for translation, Catch Up summaries and
Gocha AI, and only with the user's permission. Settings → AI features turns them
off again.

**Contact:** support@gocha.ai
